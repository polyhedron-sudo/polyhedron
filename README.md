# Polyhedron

**Polyhedron** is a browser-based, AI-assisted narrative adventure game. It combines interactive character creation, free-form storytelling, and a lightweight game engine to support evolving campaigns shaped by player decisions.

## Overview

Players create a character, enter an unfolding world, and describe what they want to do in natural language. An AI-powered Game Master interprets those actions, narrates outcomes, and responds to the changing circumstances of the adventure.

The application tracks character progression and campaign information, providing a consistent foundation for open-ended play.

## Features

- Guided character creation
- Natural-language interaction with an AI Game Master
- Dynamic narration and campaign continuity
- Character abilities, progression, and game-state tracking
- Import and export of campaign data as JSON files
- Browser-based interface suitable for desktop and mobile devices
- Configurable game server and language-model integration

## Technology

Polyhedron uses HTML, CSS, and JavaScript for its browser interface, with a Node.js backend for game processing and AI integration. The frontend can be hosted as a static website, while the backend runs on a separate web service.

The current project uses GitHub Pages for the frontend and Render for the game server.

## Playing

Open the game in a browser, connect to the game server, and follow the character-creation process. During the adventure, describe actions, questions, or intentions in the text interface and let the Game Master respond.

Use **Export** to save a campaign to a JSON file and **Import** to resume from a previously exported file. Export before closing or refreshing the page to preserve your progress.

## Project status

Polyhedron is an evolving prototype being developed and tested with a small group of players. Features and presentation may change as development continues.
